20x20 Grid Editor + Multi-run AI Learning

Draw a maze, then watch a Q-learning agent learn to reach the finish. Collect the key to unlock locked doors.

Controls

  • Startup: ↑/↓/PgUp/PgDn/Enter — set grid size (max 150x150)
  • 1 — Editor mode
  • 2 — Simulate (AI learns)
  • Click a cell to cycle its tile
  • Place a key, then click a door to point the key at it
  • Esc — cancel key pointing
  • ↑/↓/Enter — set the time limit
  • SPACE — start the AI moving
